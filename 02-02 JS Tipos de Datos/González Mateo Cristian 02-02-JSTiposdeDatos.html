1. ¿Qué etiqueta se utiliza para insertar código JavaScript en HTML?

    2. La etiqueta "<script></script>"

  2. ¿Qué ventajas tiene incrustar el código JavaScript en un archivo externo?

    • Mejor organización: separas el HTML del código JavaScript.
    • Mayor reutilización: el mismo archivo .js puede usarse en varias páginas.
    • Mantenimiento más fácil: puedes modificar el JavaScript sin tocar el HTML.
    • Código más limpio y legible: cada archivo tiene una responsabilidad más clara.
    • Mejor rendimiento en algunos casos: el navegador puede guardar el archivo .js en caché y reutilizarlo.

  3. ¿Qué extensión suelen tener los archivos que contienen código JavaScript?

  5. ¿Qué debe hacer si el archivo JavaScript se encuentra en otro directorio?
