Introductory JavaScript coursework from my DAW programme. The current assignment combines explanations and executable examples in an HTML page.

## Contents

[02-02 JS Tipos de Datos/González Mateo Cristian 02-02-JSTiposdeDatos.html](02-02%20JS%20Tipos%20de%20Datos/Gonz%C3%A1lez%20Mateo%20Cristian%2002-02-JSTiposdeDatos.html)

- Embedding JavaScript in HTML and introductory language concepts.
- Variables and constants with `var`, `let` and `const`.
- Data types and conversions with `parseInt()` and `parseFloat()`.
- String length, alerts and text output through the DOM.
- Examples of variable scope and constant reassignment.

## View the assignment

Clone or download the repository and open the HTML file in a browser with JavaScript enabled. Some examples display alerts. Open the developer console to inspect the exercises that cause errors, such as reassigning a constant or accessing a block-scoped `let` variable outside its block.

This is coursework in progress; it contains answer sections that have not yet been completed.
