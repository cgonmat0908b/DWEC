# Desarrollo web en entorno cliente · DWEC

**Español** · [English](README.en.md)

Prácticas iniciales de JavaScript del módulo DWEC de DAW. La actividad actual combina explicaciones y ejemplos ejecutables en una página HTML.

## Contenido

[02-02 JS Tipos de Datos/González Mateo Cristian 02-02-JSTiposdeDatos.html](02-02%20JS%20Tipos%20de%20Datos/Gonz%C3%A1lez%20Mateo%20Cristian%2002-02-JSTiposdeDatos.html)

- Inserción de JavaScript en HTML y conceptos iniciales del lenguaje.
- Variables y constantes con `var`, `let` y `const`.
- Tipos de datos y conversiones con `parseInt()` y `parseFloat()`.
- Longitud de cadenas, alertas y salida de texto mediante el DOM.
- Ejemplos de ámbito de variables y reasignación de constantes.

## Ver la práctica

Clona o descarga el repositorio y abre el archivo HTML en un navegador con JavaScript activado. Algunos ejemplos muestran alertas. Abre la consola del navegador para revisar los ejercicios que provocan errores, como reasignar una constante o acceder a una variable `let` fuera de su bloque.

Es una práctica en desarrollo; contiene apartados de respuesta todavía sin completar.
