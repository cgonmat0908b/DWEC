03-00 JS opciones de ejecucion

Ejercicio 1 Dado el siguiente bloque de código HTML, determina en qué orden se imprimirán los mensajes en la consola (1, 2, 3, 4, 5). (Asume que el archivo a.js pesa 50 KB y el archivo b.js pesa 2 MB).

Respuesta:

El orden de ejecución no se puede determinar con total seguridad debido al script C, que utiliza `async` y se ejecuta cuando termina de descargarse.
El script inline del body se ejecuta durante el procesamiento del HTML. Posteriormente, los scripts A y B, que utilizan `defer`, se ejecutan en ese orden, independientemente de su tamaño.
Como C pesa solamente 10 KB, es posible que se ejecute primero, pero no está garantizado.

Ejercicio 2: Selección de la mejor opción Para cada uno de los siguientes escenarios, indica si conviene usar un <script> normal, defer o async, y justifica tu respuesta: 1. Un script de Google Analytics que rastrea visitas de forma totalmente independiente. 2. La librería jQuery junto con un script propio app.js que depende de jQuery para manipular botones del DOM. 3. Un script inline muy pequeño que aplica un tema claro/oscuro antes de que el usuario vea la pantalla para evitar un parpadeo de color (FOUC).

Respuestas:

1. Async ya que no es necesario para el funcionamiento de la página

2. Defer ya que tienen que existir los elementos como los botones para que funcionase el script

3. Script normal en el head ya que ha de cargar cuanto antes
